# Инструкция по запуску WebAR примерки очков

Данный проект представляет собой WebAR-приложение для 3D-примерки очков в реальном времени с использованием веб-камеры. Для его работы требуется запустить локальный веб-сервер, а для тестирования на мобильных устройствах — настроить безопасное HTTPS-соединение через **ngrok**.

---

## Шаг 1. Запуск локального веб-сервера через Python

Современные браузеры блокируют доступ к камере по протоколу HTTP на всех устройствах, кроме `localhost` / `127.0.0.1`. Поэтому для тестирования на компьютере достаточно запустить встроенный веб-сервер Python.

### Вариант А (Самый простой — в 1 клик для Windows):
* Запустите файл **`run_server.bat`** в папке проекта. Он сам запустит Python-сервер на порту `8000`.

### Вариант Б (Через консоль вручную):
1. Откройте терминал (PowerShell или Командную строку).
2. Перейдите в папку с проектом:
   ```bash
   cd "C:\Users\user\Desktop\sweazy\Курсовая"
   ```
3. Запустите встроенный HTTP-сервер Python:
   ```bash
   python -m http.server 8000
   ```
   *(Если команда `python` не найдена, попробуйте `python3 -m http.server 8000`)*

4. Теперь проект доступен на вашем компьютере по адресу:
   [http://localhost:8000/очки.html](http://localhost:8000/очки.html)

---

## Шаг 2. Настройка ngrok для запуска на телефоне (HTTPS)

Для того чтобы открыть приложение на смартфоне или планшете, требуется **HTTPS** (шифрованное соединение), иначе мобильный браузер полностью заблокирует доступ к камере. **ngrok** создаст безопасный временный туннель к вашему локальному серверу.

Если при запуске команды `ngrok` вы видите ошибку *"ngrok не распознано как имя командлета"*, это значит, что программа не установлена или не добавлена в PATH. 

### Решение проблемы (Самый простой способ):
1. Скачайте архив ngrok для Windows: [https://ngrok.com/download](https://ngrok.com/download)
2. Распакуйте архив и скопируйте файл **`ngrok.exe`**.
3. **Вставьте `ngrok.exe` прямо в эту папку проекта** (рядом с файлом `очки.html`).
4. Зарегистрируйтесь на сайте [ngrok.com](https://ngrok.com) (это бесплатно) и скопируйте свой персональный токен (**authtoken**) из личного кабинета.
5. Авторизуйте его, запустив команду в терминале (или PowerShell) внутри папки проекта:
   ```powershell
   # Если запускаете в PowerShell:
   .\ngrok.exe config add-authtoken <ВАШ_ЛИЧНЫЙ_ТОКЕН>

   # Если запускаете в обычной Командной строке (cmd):
   ngrok.exe config add-authtoken <ВАШ_ЛИЧНЫЙ_ТОКЕН>
   ```

### Запуск туннеля:
1. Убедитесь, что ваш Python-сервер запущен (запущен файл `run_server.bat`).
2. Запустите файл **`run_ngrok.bat`**. Он автоматически найдет `ngrok.exe` в папке проекта и откроет туннель.
3. В открывшемся черном окне ngrok найдите строку **Forwarding**, которая выглядит примерно так:
   `https://xxxx-xx-xx-xx.ngrok-free.app`
   *(Важно брать ссылку именно с **https://**, а не http!)*

4. Откройте эту HTTPS-ссылку на вашем смартфоне, обязательно добавив в конец `/очки.html`.
   Например: `https://xxxx-xx-xx-xx.ngrok-free.app/очки.html`
5. Разрешите доступ к камере на смартфоне при запросе.
https://unrushed-dividers-landline.ngrok-free.dev/очки.html

## Возможные проблемы и решения

* **Камера не включается на телефоне:**
  * Убедитесь, что вы перешли по ссылке, начинающейся именно на **`https://`**, а не `http://`. Без HTTPS браузеры полностью блокируют веб-камеру в целях безопасности.
  * Убедитесь, что вы дали разрешение на доступ к камере в настройках браузера вашего телефона.
* **Ошибка загрузки нейросети / 3D-моделей (зависает на загрузке):**
  * Проверьте подключение к интернету. Приложение подгружает необходимые скрипты Face Mesh (MediaPipe) и Three.js из CDN (интернета).
  * Убедитесь, что файлы моделей `model1.glb`, `model2.glb` и `model3.glb` лежат в той же папке, откуда запущен сервер.
* **Порт 8000 уже занят:**
  * Если порт 8000 занят другой программой, измените порт при запуске:
    `python -m http.server 8080`
    И запустите ngrok для нового порта:
    `.\ngrok.exe http 8080`
